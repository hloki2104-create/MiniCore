## 🚀 快速使用

### 1. 硬件连接
- 将 RK3588 核心板对准底板接口
- 固定螺丝
- 接入 12V 电源

### 2. 上电测试
- 测量各电源电压：3.3V、1.8V、核心板供电
- 检查晶振起振

## ⚠️ 注意事项

1. 上电前请确认核心板安装方向正确
2. 避免热插拔核心板
3. 静电防护：操作前触摸接地金属
